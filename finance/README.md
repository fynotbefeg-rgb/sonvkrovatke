## Как выложить таблицу в Google Таблицы (5 минут)

1. drive.google.com → **Создать → Загрузить файл** → выберите `tablica-samozanyatogo.xlsx`.
2. Откройте файл → **Файл → Сохранить как Google Таблицу**.
3. **Настройки доступа** → «Все, у кого есть ссылка» → роль **Читатель**.
4. Скопируйте ссылку и замените в ней конец `/edit…` на `/copy`. Тогда человек по ссылке сразу получит свою копию и не увидит чужие данные.

Проверьте ссылку с другого аккаунта или в режиме инкогнито.

## Рилсы и подписи

Публикуйте один рилс в день в 19:00–21:00. После публикации отвечайте на комментарии в течение часа.

### fin01 — «3 даты»
```
Самозанятым — 3 даты, которые стоит поставить в календарь:

9-е — последний день выбить чеки за безналичные оплаты прошлого месяца
12-е — в «Мой налог» приходит квитанция
28-е — последний день оплатить налог

Если налог меньше 100 ₽, он перенесётся на следующий месяц.

Сохраните, чтобы не потерять. Правила — npd.nalog.ru.
Бесплатная таблица, которая считает налог и сроки сама, — напишите «ТАБЛИЦА» в комментариях, пришлю в директ.
```
**Первый комментарий от себя (закрепить):** `Какую из трёх дат вы пропускали чаще всего? 👇`

### fin02 — «4% или 6%»
```
Налог самозанятого зависит не от вас, а от того, кто платит:
— физлицо: 4%
— ИП или компания: 6%

Пока не закончился налоговый бонус 10 000 ₽, ставки ниже — 3% и 4%. Бонус дают один раз, остаток видно в «Мой налог».

Пример: компания заплатила 15 000 ₽ → налог 900 ₽, с бонусом 600 ₽.

Таблица, которая сама считает налог с учётом бонуса, — напишите «ТАБЛИЦА» в комментариях.
```
**Первый комментарий:** `Вы работаете больше с физлицами или с компаниями?`

### fin03 — «Вычет за лечение»
```
Самозанятые часто спрашивают, можно ли вернуть 13% за лечение или обучение.

Налоговый вычет возвращает НДФЛ — налог с зарплаты. Налог самозанятого (НПД) — это не НДФЛ. Если у вас только доход самозанятого, возвращать нечего.

Если есть зарплата или другой доход, с которого платится НДФЛ, вычет можно получить — с этого дохода.

Бесплатная таблица самозанятого — напишите «ТАБЛИЦА» в комментариях.
Информация справочная, не является налоговой консультацией.
```
**Первый комментарий:** `Знали об этом? Напишите «да» или «нет»`

## Ответ в директ

Отправлять каждому, кто написал «ТАБЛИЦА»:
```
Привет! Держите таблицу самозанятого 👇
<ссылка /copy>

Как пользоваться: каждую оплату — строкой на листе «Доходы», всё остальное таблица посчитает сама. Итоги по месяцам и остаток до лимита — на листе «Итоги».

Чем вы занимаетесь как самозанятый? Соберу частые вопросы и разберу их в следующих роликах.
```

Ответ на «чем занимаетесь» — это исследование аудитории. Записывайте ответы: из них получится платный продукт.

### Как опубликовать на Netlify (10 минут)

1. app.netlify.com → **Add new site → Import an existing project** → GitHub → репозиторий `sonvkrovatke`.
2. **Branch to deploy:** `main`, когда ветку смёржат. До этого — `claude/plugin-marketplace-ui-ux-pro-max-x0sp6q`.
3. **Base directory:** `finance/site`. **Publish directory:** `finance/site`. Build command — пусто.
4. **Deploy.** Сайт откроется на адресе вида `имя.netlify.app`. Имя можно сменить: Site configuration → Change site name, например `dengi-samozanyatogo`.
5. **Forms → Enable form detection**, затем Deploys → Trigger deploy. Иначе форма вернёт 404, как было на первом сайте.
6. Forms → Form notifications → письмо на вашу почту о каждой новой заявке.
