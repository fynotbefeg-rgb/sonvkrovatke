    "canonicalPath": "/"

  {
    "path": "/services",
    "canonicalPath": "/"

    "canonicalPath": "/pricing"
  },
  {
    "path": "/contact",
    "canonicalPath": "/contact"
  }
]

Предлагаемый шаг: В этом стенде разные самостоятельные страницы должны ссылаться canonical на себя; проверить адреса. Не переносить правило на дубликаты без анализа.
