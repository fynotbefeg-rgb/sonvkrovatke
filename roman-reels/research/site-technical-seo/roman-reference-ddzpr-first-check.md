## Подтверждённые первичные источники

1. https://github.com/every-app/open-seo — README проекта прямо указывает обязательный DataForSEO API key для SEO-данных при самостоятельном размещении и оплату запросов. MIT/open-source не означает бесплатность ключей, позиций и бэклинков. Это найденный кандидат на название Open SEO; связь именно с показанным в ролике репозиторием пока не установлена.
2. https://code.claude.com/docs/en/overview — большинство способов доступа требуют Claude subscription или Anthropic Console; настольный продукт требует платную подписку. Бесплатная установка плагина не доказывает бесплатную работу всей связки. Уже оплаченная подписка владельца не делает реализацию бесплатной для зрителя.
3. https://developers.google.com/search/docs/appearance/ai-features и https://developers.google.com/search/docs/fundamentals/ai-optimization-guide — Google сохраняет обычные SEO-основы для AI-функций, специальная schema не требуется. Нельзя обещать цитирование конкретного сайта вместо конкурентов после установки skill. Это проверка утверждения о Google; не технический тест ChatGPT/Claude.
4. https://github.com/thelocalpit/gsc-mcp — пример MCP с MIT-лицензией, OAuth и readonly доступом к GSC, запросами clicks/impressions/CTR/position и инспекцией URL. Он требует доступ к ресурсу GSC и настройку OAuth; название GSC MCP неоднозначно. Не установлен, не запущен и не идентифицирован как плагин из референса.

Средняя позиция не является фиксированной позицией выдачи и не гарантирует быстрый рост. Это проект демонстрации, а не уже работающий процесс.
