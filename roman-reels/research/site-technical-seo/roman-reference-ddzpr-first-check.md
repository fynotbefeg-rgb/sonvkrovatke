## Подтверждённые первичные источники

1. https://github.com/every-app/open-seo — README проекта прямо указывает обязательный DataForSEO API key для SEO-данных при самостоятельном размещении и оплату запросов. MIT/open-source не означает бесплатность ключей, позиций и бэклинков. Это найденный кандидат на название Open SEO; связь именно с показанным в ролике репозиторием пока не установлена.
2. https://code.claude.com/docs/en/overview — большинство способов доступа требуют Claude subscription или Anthropic Console; настольный продукт требует платную подписку. Бесплатная установка плагина не доказывает бесплатную работу всей связки. Уже оплаченная подписка владельца не делает реализацию бесплатной для зрителя.
3. https://developers.google.com/search/docs/appearance/ai-features и https://developers.google.com/search/docs/fundamentals/ai-optimization-guide — Google сохраняет обычные SEO-основы для AI-функций, специальная schema не требуется. Нельзя обещать цитирование конкретного сайта вместо конкурентов после установки skill. Это проверка утверждения о Google; не технический тест ChatGPT/Claude.
4. https://github.com/thelocalpit/gsc-mcp — пример MCP с MIT-лицензией, OAuth и readonly доступом к GSC, запросами clicks/impressions/CTR/position и инспекцией URL. Он требует доступ к ресурсу GSC и настройку OAuth; название GSC MCP неоднозначно. Не установлен, не запущен и не идентифицирован как плагин из референса.

## Вывод для первого ролика

По предоставленному тексту можно адаптировать структуру: понятная проблема затрат → конкретные инструменты → демонстрация бизнес-результата → CTA. Визуальный монтаж, темп и экранные шаги пока не просмотрены; вывод о них невозможен.

Не повторять без проверки: экономию $3346/год, полную замену Semrush/Ahrefs/Yoast, бесплатность всей связки и гарантии ранжирования/цитирования.

Практическая гипотеза для демонстрации: собственные данные Search Console → запросы с показами и средней позицией 8–20 → соответствующие страницы → проверка технических препятствий и конкретный приоритет исправлений. Средняя позиция не является фиксированной позицией выдачи и не гарантирует быстрый рост. Это проект демонстрации, а не уже работающий процесс.

Следующий минимальный шаг первоначально предполагал запрос ссылок у Романа; после самостоятельного поиска ниже это больше не требуется для исследования. Идентичность репозиториев в самом рилсе всё ещё не подтверждена. Не предоставлять Google доступ и не запускать платные SEO API. Дальше — один проверяемый пример на доступных данных Романа, затем основа и три хука после выбора темы.

Настройка Apps Script продолжается отдельно: по скриншотам владельца один активный Web app, Version 3, execute as Me, access Anyone. Это не доказывает соответствие опубликованного кода приватному backup и не даёт согласия на deployment. Первый выпуск не должен ждать этой настройки.

2026-10-12 найден публичный разбор https://www.riccardobelli.com/seo-claude-code/ (указано обновление 4 октября 2026), перечисляющий ровно три проекта. Команды установки из блогов не выполнялись, инструменты не подключены к нашему Claude, Google права не выданы, платные вызовы отсутствуют. Сопоставление с видео можно дополнить чтением публичной страницы/видимых кадров через существующий Windows MCP, если Instagram доступен; не входить в чужие аккаунты, не писать комментарии/DM от владельца и не обходить ограничения.

Минимальная гипотеза бесплатной демонстрации: экспорт собственных данных GSC + локальные технические проверки/базовый GEO audit без AI-provider calls. Claude Code с подпиской может быть нашим инструментом подготовки, но обязательный платный Claude в инструкции зрителю нарушает текущий критерий полной бесплатности. Аудит не превращать в обещание роста/замены Ahrefs. Для показа сайта Романа ещё нужны адрес/разрешённые данные; фикстура доказывает только учебные проверки.
