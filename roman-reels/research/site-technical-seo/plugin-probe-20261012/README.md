# Практическая проверка SEO-инструментов

2026-10-12. Выполнено Codex в облачной Linux-среде; не на Windows и не на сайте Романа. Инструменты не подключались к Google аккаунтам. Оплаты, SEO API, генерации сценариев, утверждений и deployments не было.

## Что реально выполнено

- Из PyPI в отдельную временную venv установлен **geo-optimizer-skill 4.19.0** с базовыми зависимостями, без extras llm/embedding/mcp. Системные компоненты и Windows не менялись. Исходники рассмотрены, но полная безопасность всех зависимостей не проверялась.
- CLI `geo audit --url https://example.com --format json --no-plugins --output ...` завершился с кодом 0 и JSON без ошибки. Аккаунт/API key не запрашивался, citations/fix/--apply не выполнялись. Один smoke-тест доказывает запуск базового аудита, а не бесплатность всей связки Claude и не полный аудит реального сайта.
- Полученный балл 22/100 — внутренняя эвристика, НЕ вероятность цитирования, не SEO-оценка Google и не измерение бизнес-эффекта. Никакого роста/индексации/цитирования не измеряли.
- Модуль `audit_js_rendering` протестирован на собственной заведомо статической короткой странице без script-тегов. Все слова уже в HTML, но `js_dependent=true`. Воспроизводимый пример и результат приложены. Поэтому выдавать каждую рекомендацию этого инструмента как найденную техническую ошибку нельзя.

Example.com возвращает основной текст в HTML и дополнительно имеет s.js с переводами. Первоначальное сообщение о полностью статическом example.com было неточным; отдельный собственный counterexample устраняет неоднозначность. Example.com — документальный адрес, не сервис для постоянного мониторинга; повторный цикл/нагрузка не запускались.

## GSC MCP: проверка кода, не подключение аккаунта

Проект https://github.com/AminForou/mcp-gsc, commit `d49eea9e5efb5eb645b722249303179b2c150b49`, версия pyproject 0.4.1.

- `gsc_server.py:106`: SCOPES использует `https://www.googleapis.com/auth/webmasters`, а НЕ `webmasters.readonly`.
- `gsc_server.py:1542–1586`: submit_sitemap вызывает Google API записи без проверки ALLOW_DESTRUCTIVE. Управление sitemap может вызывать эту функцию.
- GSC_ALLOW_DESTRUCTIVE=false блокирует отдельные операции удаления/добавления ресурсов, но не делает весь MCP read-only. Вход в Edge также не является авторизацией этого MCP.
- Не установлен и не импортирован, реальный OAuth/чтение GSC не проверены. Для демонстрации только чтения потребуется отдельно проверенный readonly вариант либо безопасный экспорт CSV. Не выдавать изменение одного prompt за ограничение OAuth-полномочий.

## OpenSEO и применимость для сценария

https://github.com/every-app/open-seo: README сообщает, что SEO-данные требуют DataForSEO API key и оплачиваются отдельно. Эти операции не запускались. Проект не подходит для обещания бесплатных keyword/backlink/rank данных.

GEO audit может дать полезные фактические наблюдения, но рекомендации про llms.txt, +40% видимости, обязательный canonical/schema и минимальное число слов требуют отдельной проверки. Отсутствие robots.txt не означает запрета обхода. Google не требует llms.txt или специальной schema для AI-функций: https://developers.google.com/search/docs/fundamentals/ai-optimization-guide. Не копировать такие утверждения в сценарий.

## Решение для первого выпуска

Не снимать обещание «три бесплатных плагина полностью заменяют платные SEO-сервисы». Проверяемая гипотеза: собственная выгрузка GSC → запрос/страница → подтверждённая техническая проблема → конкретное исправление. Для этой демонстрации нужны разрешённые данные/сайт Романа; тема и текст ещё не утверждены. Наш платный Claude — средство подготовки, не бесплатное требование к зрителю.

Следующее действие владельца, когда доступно: получить у Романа публичный URL сайта для проверки. До этого можно подготовить демонстрацию на собственном стенде, явно учебную; не подменять ею результаты клиентского сайта. Apps Script дорабатывать отдельно, без блокировки первого выпуска.

## Артефакты

`example-audit.json` — исходный машинный отчёт, рекомендации **не одобрены**. `static-counterexample.py/json` — собственный воспроизводимый контрпример. `manifest.json` — SHA256 и границы проверки. Проверено чтение JSON, успешный CLI и воспроизводимость ложного срабатывания; художественный/SEO результат не проверен.
