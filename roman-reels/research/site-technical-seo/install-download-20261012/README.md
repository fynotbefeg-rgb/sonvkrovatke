# install.download: первая проверка реального сайта

2026-10-12. URL предоставлен владельцем проекта для SEO-демонстрации. Только чтение публичных страниц; сайт не изменялся, доступ в Google не предоставлялся, файлы программ не скачивались. Это ограниченная выборка, не полноценный SEO-аудит и не доказательство одобрения темы Романом.

## Подтверждённые наблюдения

| Проверка | Результат | Значение |
| --- | --- | --- |
| Главная / и русская /ru | HTTP 200, по одному H1, title/description есть | В исходном HTML есть доступный контент; технических запретов noindex в проверенных meta не найдено. Это не подтверждает индексацию Google. |
| robots.txt | 200; sitemap указан; login/dashboard/seo-backlinks и часть query URL запрещены | Запрет служебных URL не считать ошибкой. Запрещённые пути не запрашивались. |
| /sitemap.xml | 404 | Не ошибка отсутствующей карты: сайт указывает другой адрес в robots.txt. |
| /sitemaps/index_sitemap.xml | 200, XML разобран, 464 карты | Доступная карта найдена. Все карты и перечисленные страницы не обходились. |
| Английская карта категорий Windows | 200, XML разобран, 121 URL; business и browsers присутствуют | Проверены наличие двух категорий в карте и их HTTP 200. |
| Заведомо отсутствующая страница | 404 | Проверяемый пример корректного ответа, soft-404 в этой пробе нет. |
| /windows/business и /windows/browsers | 200, отдельные title/description, один H1; rel=canonical в HTML не найден | Кандидат на улучшение управления дублями, не доказанная причина потери трафика. Без canonical Google может выбрать URL сам. HTTP Link header этих двух страниц не проверялся. |
| Opera GX EN/RU | 200, self canonical у обеих страниц; ссылки hreflang друг на друга есть | Правильные признаки на проверенной паре; остальные 14 языков не проверены. |
| Главные EN/RU | hreflang взаимный, canonical в HTML не найден; на /ru нет canonical и в HTTP Link header | Проверка выбираемого Google canonical требует Search Console, отсутствие тега само по себе не критическая ошибка. |

Начальный сборщик читал Content-Type/X-Robots-Tag с учётом регистра ключей, поэтому null в первой пробе не доказывает отсутствие заголовков. Не делать вывод о заголовках главной из этих значений. Последующие сборы нормализовали ключи. Hreflang и canonical — наблюдения HTML; для английской главной также выполнен GEO audit, подтвердивший отсутствие canonical в его разборе.

## Реальный запуск найденного инструмента

GEO Optimizer 4.19.0 выполнил `geo audit --url https://install.download/ --format json --no-plugins` с кодом 0, error=null, без аккаунта/API key. Балл 36/100 — только оценка этого инструмента; не вставлять в ролик как оценку Google или потерянную долю продаж/трафика. Среда — облачный Linux, не ноутбук Windows.

Инструмент нашёл контент в HTML и рабочую sitemap. Его рекомендации про обязательные 300/500 слов, FAQ/schema, llms.txt, +40% AI-видимости и keyword stuffing по повторению пунктов каталога НЕ прошли проверку. Не выдавать их за обязательные правила/подтверждённые проблемы. Ранее на своей статической фикстуре подтверждено ложное срабатывание JS-эвристики.

## Что можно показать сейчас

Реальные бесплатные проверки: получить HTTP-статус → прочитать robots → перейти по объявленной sitemap → проверить title/H1/canonical/hreflang выбранной страницы. Можно показать, как перепроверка устраняет ложное «карты сайта нет». Для исправления реального недостатка и приоритета бизнес-эффекта пока нет достаточных данных; не придумывать ошибку ради демонстрации.

Технический кандидат: согласованная canonical-разметка главной/категорий при наличии дублей. Сначала проверить конкретные дубли и выбранный Google canonical; не применять теги ко всем языкам на одну английскую страницу, не обещать рост после добавления тега. Сайт не исправлялся.

## Следующий минимальный шаг для SEO-ролика

Получить от Романа экспорт **Эффективность → Результаты поиска** Search Console за последние 3 месяца (стандартная выгрузка с вкладками запросов/страниц). Не нужен пароль или админ-доступ. Выбрать страницу по собственным показам/кликам/CTR и сверить её публичную техническую часть. Экспорт запросов и страниц по отдельности НЕ даёт соответствие query→page: для такого вывода нужна отдельная фильтрация или выгрузка этих измерений вместе. Пока выгрузки нет, данные трафика/CTR/позиций неизвестны.

После проверки — конкретная карточка темы и затем основа/три хука для утверждения. Сайт не заменяет недостающую статистику внешнего референса. Полная автоматизация Apps Script продолжается отдельно; paid SEO API/новые MCP не требуется подключать для этого первого шага.
