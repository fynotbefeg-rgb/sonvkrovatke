# RustDesk через Tailscale без публичного сервера: проверка тарифа, 2026-10-12

Запрос владельца: прямое подключение RustDesk с iPhone через Tailscale, без публичного сервера RustDesk; проверить применимость бесплатного тарифа; без платных услуг, без открытых портов в интернет; текущее подключение сохранить.

## Итог: BLOCKED — бесплатный тариф Tailscale не подходит для нашего использования

Официальная страница https://tailscale.com/pricing (прочитана 2026-10-12):

- Personal: $0, «Free forever», до 6 пользователей, неограниченно пользовательских устройств.
- «Our Personal plan is for individuals who want to use Tailscale at home.»
- «This is a free plan and is only suitable for non-commercial use of Tailscale.» / «the Personal plan is not intended for commercial use.»
- Для бизнеса — 14-дневный пробный период, затем платные тарифы.

https://tailscale.com/kb/1154/free-plans-discounts (Last validated Apr 8, 2026) подтверждает лимит 6 пользователей, но о коммерческом использовании отсылает к странице цен.

Ноутбук используется для производственного проекта роликов Романа — это деловое использование. Personal-тариф по его условиям для этого не предназначен; пробный период как единственный путь по правилам проекта не подходит (CONTENT_REQUIREMENTS.md, R06/R07 — для зрителя; для самой студии платные услуги без согласия не подключаются). Поэтому Tailscale не устанавливался.

Проверенная альтернатива — ZeroTier (https://www.zerotier.com/pricing/): бесплатный план «Personal, non-commercial use», коммерческая лицензия только на платных тарифах. Тот же блокер.

## Что сделано и не сделано

- Tailscale не скачивался и не устанавливался, аккаунт не создавался.
- Прямой IP-доступ RustDesk (порт 21118) не включался, правила брандмауэра не менялись, порты в интернет не открывались.
- Текущее подключение RustDesk через публичные серверы сохранено: служба `RustDesk` работает, пароль и ID не менялись. Edge (google-project) и MCP не трогались.
- Пароли, ключи и ID в отчёт не включены.

## Варианты, которые решает владелец

1. Если владелец считает удалённый доступ к своему ноутбуку личным (некоммерческим) использованием — это его решение и ответственность по условиям Tailscale; тогда можно продолжить: официальный MSI Tailscale, вход владельца по ссылке с iPhone, RustDesk direct IP только из диапазона Tailscale 100.64.0.0/10 через правило брандмауэра.
2. Оплатить коммерческий тариф Tailscale/ZeroTier — только после отдельного согласия.
3. Оставить текущую схему RustDesk через бесплатные публичные серверы (она уже работает как служба; подключение с iPhone ещё не проверено владельцем).
