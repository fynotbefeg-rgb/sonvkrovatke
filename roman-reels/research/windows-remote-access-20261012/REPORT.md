## Почему без администратора не выйдет

Portable-версия принимает подключение только по временному паролю, который показывается в её окне на ноутбуке и меняется. Без человека у экрана его не узнать. Постоянный пароль, работа на экране блокировки, UAC и запуск после перезагрузки требуют установки RustDesk как службы, а это права администратора. Править зашифрованный конфиг вручную в обход программы я не стал.

Учётная запись пользователя входит в группу «Администраторы», а UAC настроен повышать права без запроса (`ConsentPromptBehaviorAdmin = 0`). Поэтому установка службы, скорее всего, пройдёт без подтверждения у ноутбука — но это установка с правами администратора, на которую нужно отдельное согласие владельца.

## Если владелец разрешит установку

1. Установить тот же проверенный `rustdesk-1.5.0-x86_64.exe` как службу (тихая установка), используя бесплатные публичные серверы RustDesk.
2. Задать случайный постоянный пароль; ID и пароль передать владельцу только в личном чате, не в Git и не в логи.
3. Рекомендуется включить в RustDesk двухфакторную проверку (TOTP) и разрешить только вход по постоянному паролю.
4. На iPhone поставить бесплатное приложение RustDesk из App Store и подключиться по ID и паролю.

Риски: служба даёт полный доступ к ноутбуку, включая экран блокировки и вошедшие аккаунты браузеров. Единственная защита — пароль (и 2FA, если включить). Публичные серверы RustDesk бесплатны, но без гарантий доступности.

## Проверка подписи и настроек, 2026-10-12

- Повторная проверка Authenticode: и скачанный установщик, и установленный `C:\Program Files\RustDesk\rustdesk.exe` — **Valid**, «Signature verified». Цепочка `PURSLANE ← Sectigo Public Code Signing CA EV R36 ← Sectigo Public Code Signing Root R46` строится и с онлайн-проверкой отзыва, и без неё; есть метка времени Sectigo. Корень R46 есть в хранилище доверенных корней. Файл не повреждён (SHA-256 совпадает с релизом), издатель доверенный.
- Причина первого `UnknownError`: при первой проверке цепочку не удалось достроить. Это совпадает с кратким сбоем сети к внешним узлам в то же утро; при повторной проверке Windows достроила цепочку. Точную внутреннюю причину по журналу не восстановить, но ни повреждения файла, ни недоверенного издателя нет. UAC и защита Windows не отключались.
- Настройки службы RustDesk (только нечувствительные строки конфига): `approve-mode = 'password'`, `verification-method = 'use-permanent-password'` — вход только по постоянному паролю, без подтверждения у ноутбука.
- Повышение прав снова прошло без окна UAC. Edge google-project и старый MCP работают.
- Подключение с iPhone по-прежнему NOT_TESTED.
