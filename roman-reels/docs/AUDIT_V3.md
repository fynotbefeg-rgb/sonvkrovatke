## Проверки этой среды

- 45 тестов в семи `scripts/*.test.mjs`: 4 Apify access + 5 Apify one Reel + 10 Apps Script + 8 intake + 2 Claude job + 4 review + 12 queue. Все проходят; внешние сервисы замоканы.
- `cd roman-reels/pv && npx remotion bundle --out-dir /tmp/roman-audit-v3-bundle` — успешно.
- `npx tsc --noEmit` — не проходит: 8 существующих ошибок. AiReel: unused PAN_S3 / duplicate key; FaceReel: unused winP, ins; FormulaReel2: unused F; FormulaReel3: unused F / duplicate key; LudiVideo: unused Sequence. В этом этапе эти компоненты не изменены.
- `package.json`: метаданные относятся к старому Son-проекту; default render использует SleepReel, которого нет в текущем Root. Исправление — задача Claude, без создания нового проекта.
- `render-quality.mjs` запускает рендер, но не обеспечивает сам по себе авторизацию производства и полную проверку качества.
- В Python этой среды отсутствуют faster-whisper, WhisperX, torch, Silero VAD, MediaPipe, OpenCV, librosa. FFmpeg/ffprobe и jsonschema 4.26.0 доступны. Это не утверждение о пакетах будущего runner.

Разрешённая цель следующего этапа — разработческий тест, без публикации и статуса готового production-ролика.

## Границы доступов

GitHub checkout/fetch и чтение Actions доступны. Доступ администратора к Secrets ранее получал 403;
значения Secrets не извлекаются. У среды нет авторизованного Windows/HeyGen/Claude-сеанса.
Существующие rclone credentials в Actions не означают доступ любого локального процесса к Drive.
Новая папка incoming и доступ сервисного аккаунта требуют отдельной проверки.
