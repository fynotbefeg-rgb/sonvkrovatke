# Пробный сбор одного Reel — подготовлено, не запущено

Источник пользователя: https://www.instagram.com/reel/Dd-BrltxRS1/ . Автор и содержимое пока не подтверждены: обычный веб-запрос Instagram ограничен, поиск по shortcode результатов не дал.

Пользователь дополнительно дал профиль https://www.instagram.com/founder.roman/ ; tracking-параметр удалён. Источник записан в `research/roman-instagram-source.json`. Обычный запрос к профилю также ограничен. Связь указанного Reel с этим автором ещё надо проверить по результату сбора; ссылку на профиль нельзя считать разрешением на платный запуск или массовый сбор. Первый подготовленный тест по-прежнему касается только одного исходного Reel.

Выбран официальный Actor `apify/instagram-reel-scraper`. [Схема ввода](https://apify.com/apify/instagram-reel-scraper/input-schema) подтверждает приём прямой ссылки в `username`; `resultsLimit` при прямых Reel URLs не ограничивает сбор, поэтому в input передаётся ровно одна ссылка, без профиля или других источников. План сохранён в `research/roman-first-reel-plan.json`.

По [публичному прайсу](https://apify.com/apify/instagram-reel-scraper/pricing), проверенному 2026-10-09, тариф Free: $2.60 за 1000 базовых результатов и $0.001 за запуск. Ориентир для одного результата — $0.0036. Тариф аккаунта и наличие кредитов этой оценкой не проверены. Расшифровка, скачивание видео и shares count отключены, поскольку являются отдельными платными дополнениями. Запуск может расходовать кредиты Apify.

В `apify-one-reel.mjs` установлены API-параметры `maxTotalChargeUsd=0.05`, `timeout=120`, `restartOnError=false`; [документация лимита API](https://docs.apify.com/api/v2/actors-runs-post) описывает максимальную стоимость запуска. Код никогда автоматически не повторяет POST создания Actor, фиксирует удалённый run ID до polling и останавливается при ошибке/неоднозначном результате. При сетевой ошибке создания надо проверить Apify вручную, прежде чем запускать повторно: удалённая задача могла быть создана.

Проверяется ровно один совпадающий shortcode в dataset. В artifact сохраняются подпись, автор, дата, доступные публичные счётчики и длительность; отсутствие метрики обозначается `null`. Комментарии пользователей, CDN-ссылки видео/аудио и данные аккаунта не включаются. Это сбор метаданных, а не просмотр видео или анализ речи; Insights, удержание и заявки недоступны из публичного ролика.

Пять тестов лимита/ввода/подтверждения/отказов прошли локально. Ручной зарегистрированный workflow `roman-reels-check.yml` имеет отдельный флаг `collect_one_apify_reel` (по умолчанию false); в этом режиме обычный Remotion и проверка аккаунта пропускаются. Запуск возможен только в рабочей ветке. При подтверждении пользователем единственного запуска с лимитом $0.05 Codex может dispatch workflow с `collect_one_apify_reel=true` и исходной ссылкой. Не менять main, не запускать массовый сбор и не использовать это разрешение для других роликов или платных дополнений.
