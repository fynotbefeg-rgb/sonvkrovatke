## Задача Claude Code

Работай на Windows с существующим клоном C:\Users\Антон\work\sonvkrovatke. Первый этап — проверка без изменений рабочей копии, установки пакетов, генерации, входа в аккаунты и обращения к HeyGen. Не считать подписку Claude Pro/Max бесплатным решением для зрителя.

1. Прочитай применимые AGENTS.md. Проверь путь, origin, текущую ветку, рабочее дерево и stash. Незнакомые изменения/старые .playwright-mcp файлы не удалять. Выполни git fetch origin; не выполнять pull, reset, checkout, merge, rebase или изменение main. Для актуальных документов использовать git show origin/feature/codex-pipeline:roman-reels/docs/CODEX_HANDOFF.md и аналогично CONTENT_REQUIREMENTS.md, SEO_GROUNDED_PROBE_V2.md, WINDOWS_SETUP.md. Если GitHub недоступен, указать точную ошибку, не создавать новый репозиторий.
2. Проверь версию Windows, CPU, общий RAM, GPU (без предположений о пригодности), свободное место и наличие Git/Node/Python/FFmpeg/Claude Code. Не ставить отсутствующее. Не выводить environment, секреты, токены, cookies, личные документы или полные конфигурации MCP.
3. В текущей сессии найди настоящие инструменты Playwright MCP. Состояние сервера Connected само по себе не доказывает доступ инструментов. Если инструментов нет, остановить браузерную часть и явно сообщить: нужна новая сессия с подключённым MCP. Не подменять эту проверку отдельным скриптом.
4. Если инструменты есть, через них открыть только https://example.com и прочитать заголовок страницы. Указать реально вызванные инструменты, результат и фактический браузер. Не менять профиль/isolated/headless конфигурацию, не входить в HeyGen/Google, не открывать личные вкладки и не запускать генерацию. Авторизацию и постоянный профиль согласовать отдельным этапом.
5. Вернуть короткий отчёт: GitHub/ветка/HEAD после fetch, чистота рабочей копии, характеристики, версии, доступные MCP-инструменты, результат Example Domain, блокеры. Git fetch обновляет origin refs, а не текущую ветку: не называть локальную копию актуальной, если HEAD отстаёт. Отчёт вернуть пользователю; автоматически никому не отправлять. Файлы репозитория не менять и не коммитить на этом этапе.
