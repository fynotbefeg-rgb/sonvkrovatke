## C1 — минимальный Director для одного целого MP4

Вход: контракт v1, точные слова из реального аудио, сегменты, каталог разрешённых визуальных ресурсов.
Выход: montagePlan с привязкой к индексам слов, временем, ресурсом, animation, position,
layer, transition и safe-zone ограничениям. Не редактировать исходный сценарий.
Для первого шага достаточно детерминированного смыслового разбора известных терминов и тезисов;
отдельные эвристики описать, не называть их доказанным полноценным пониманием текста.
Не вызывать Claude API/CLI в каждом рендере. Нужен обычный исполняемый модуль со стабильным seed от reelId.

Первый клип: `pv/public/ai/body1.mp4`, только development fixture.
Не брать его старые word timings: Codex передаёт новую проверенную транскрипцию.
Не дублировать hook, уже входящий в scriptText. Ресурс без подтверждённых прав исключать;
если интерфейса инструмента нет, допустима типографическая карточка без чужих скриншотов.

Критерии: все события связаны с реальными словами; нет выхода за duration;
нет неизвестных asset IDs; минимум одна осмысленная карточка/акцент по содержанию;
паузам и лицу остаётся пространство; перегрузка эффектами ограничена явными правилами.
Тесты: пустые слова, отсутствующий термин/asset, короткий клип, перекрытие элементов,
детерминированность, отказ от несовместимой schemaVersion.

## C2 — существующий Remotion как автоматический движок

Добавить композицию для полного sourceVideo + montagePlan, не новый проект.
Субтитры: активное слово, переносы, крупный читаемый шрифт, ограничение числа слов,
анимация появления, безопасные зоны. Источник сохраняет речь и длительность;
изменения скорости и нарезка требуют отдельного контракта source↔timeline.
Карточки/акценты/небольшие приближения — сначала; B-roll/split-screen — после базовой проверки.
Не перекрывать лицо; пока face tracking не проверен, использовать консервативную раскладку
и контрольные кадры, не заявлять автоматическое обнаружение лица.

Критерии: один 1080×1920 MP4 с аудио, повторяемый CLI-рендер по JSON без интерактивной студии;
динамический duration из проверенных метаданных, не статическая тема.
Тесты: активное слово на границах кадров, перенос длинных русских слов, safe zones,
слои/переходы, отсутствующий файл, ключевые stills до/во время/после событий, полный тестовый рендер.
Передать Codex composition ID, точную CLI-команду, fixtures и список ограничений.

## C3 — профессиональное качество после P1

Развить каталог B-roll, схем, чисел, интерфейсов, split-screen и переходов;
несколько воспроизводимых стилей при единой айдентике. Музыка только с разрешёнными правами.
Оценить темп, разнообразие, читаемость и положение лица на серии тестовых роликов.
Автоматическая геометрия не заменяет просмотр владельцем контрольных кадров.
