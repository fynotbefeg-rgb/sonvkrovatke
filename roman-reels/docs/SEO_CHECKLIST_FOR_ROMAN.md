# Что проверить после создания сайта с ИИ

Редакционный материал Codex, 2026-10-11. Не утверждённый сценарий.
Приоритет уточнён Романом: чек-лист важнее анализа конкретного клиентского
сайта. Search Console — короткая демонстрация экспорта. Запрашивать доступ
к сайту ради подготовки этого материала не требуется.

## Чек-лист для владельца бизнеса

| Что проверить | Как проверить | Результат для отчёта |
| --- | --- | --- |
| Доступность важных страниц | Открыть главную, услуги, контакты; проверить HTTP-ответы | URL, код ответа, время проверки |
| Ограничения обхода | Прочитать robots.txt для нужного робота | Правило и затронутые страницы; robots не доказывает отсутствие в индексе |
| Запрет индексации | Проверить meta robots и X-Robots-Tag | Найденный noindex и решение владельца: нужен ли он здесь |
| Карта сайта | Прочитать sitemap, проверить адреса основных страниц | Пропуски/недоступные URL; карта не гарантирует индексацию |
| Дубли адресов | Сопоставить варианты URL, редиректы и canonical | Предпочтительный адрес и противоречащие сигналы |
| Битые ссылки | Пройти внутренние ссылки в согласованных пределах | Откуда ведёт ссылка, куда, какой HTTP-ответ |
| Содержание страницы | Сопоставить предложение бизнеса с запросом клиента | Какую задачу страница решает; что нужно уточнить у владельца |
| Заголовки и описание | Прочитать title, description и структуру заголовков | Понятен ли смысл, нет ли случайного шаблона; не считать один H1 универсальным законом |
| Связи между страницами | Проверить меню и ссылки на важные услуги | Как пользователь и робот могут найти страницу |
| Скорость | Измерить PageSpeed/Lighthouse, отдельно проверить полевые CWV при наличии | URL, дата, устройство, измерения и условия; не только общий балл |
| Использование с телефона | Проверить читаемость, меню, кнопки и форму на тестовой копии | Сценарий, ожидаемый результат, наблюдение; это также UX/конверсия |
| Видимость в Google | При наличии доступа: URL Inspection и отчёт индексации | Данные Google на дату проверки; исходники сайта их не заменяют |
| Поисковые показатели | Экспорт Performance с периодом и фильтрами | Клики, показы, CTR, средняя позиция; не продажи и не уникальный охват |

Для всех пунктов: «проверено», «нужны данные», «не применимо».
Отсутствие доступа не превращать в «всё хорошо». Чек-лист задаёт основу,
а не гарантирует полноту SEO-аудита. Для магазинов, локального бизнеса и
многоязычных сайтов нужны дополнительные проверки разметки и структуры.
Без согласования не менять сайт и не отправлять реальные заявки.

## Одна короткая демонстрация Search Console

План будущей записи экрана, а не выполненная проверка интерфейса:

1. Выбрать подтверждённый ресурс сайта.
2. Открыть «Эффективность» → результаты поиска; задать период и тип поиска.
3. Включить нужные показатели и нажать «Экспорт». Проверить содержимое файла.
4. Прикрепить выгрузку к Claude и передать промпт ниже.

Показать только участок с нужными настройками, экспортом и загрузкой файла.
Скрыть личные данные, аккаунт и лишние ресурсы. Названия меню уточнить по
реальной записи перед монтажом. Подключение MCP — отдельная инструкция:
в этой демонстрации обязательный сторонний коннектор не нужен.

## Промпт: проверка сайта и подготовка задач

> Проведи проверку по приложенному SEO-чек-листу. Сначала перечисли доступные
> файлы сайта, выгрузки и инструменты. Для каждого пункта укажи статус:
> проверено / нужны данные / не применимо. Подтверждай находки URL, фрагментом
> файла, HTTP-ответом или строкой отчёта. Отделяй наблюдение от гипотезы.
> Для важных страниц проверь запреты обхода и индексации, sitemap, canonical,
> редиректы, ссылки и содержание. Если невозможно получить страницу или
> внешний отчёт, сообщи, что именно отсутствует; ничего не додумывай.
> Не считай отсутствие description или нескольких H1 автоматическим штрафом.
> Не объединяй отдельные сводки Queries и Pages в пары запрос–страница.
> Сформируй задачи: проблема, доказательство, предлагаемая правка, приоритет,
> способ перепроверить. Без моего разрешения не меняй сайт. Не обещай рост
> позиций и трафика. Фактическую индексацию и полевую скорость без данных
> Google не объявляй проверенными.

Промпт пока не испытан в Claude; качество результата требует отдельной
проверки. Бесплатность файла/чек-листа не означает отсутствие тарифов у ИИ.

## Смысл короткого ролика

Предварительная структура: сайт создан → какие проверки поручить ИИ →
показать два-три примера доказательств → где выгрузить Search Console →
получить задачи → предложить полный чек-лист. Все 13 пунктов произносить
в одном коротком видео не нужно: полный материал выдаётся отдельно.

Три направления хуков для будущего Gemini-брифа (Codex, не готовая речь):

1. «Сайт с ИИ уже готов? Перед запуском дай ему этот список проверок».
2. «Попросить Claude “проверь SEO” мало. Вот какие данные и проверки ему нужны».
3. «Как получить от ИИ задачи по SEO с доказательствами, а не общие советы».

Не приписывать Claude выполнение наших прежних учебных тестов. До новой
проверки, генерации и утверждения не заменять пакет v5 и не записывать речь.
Сильный доступный внешний референс ещё требуется.
