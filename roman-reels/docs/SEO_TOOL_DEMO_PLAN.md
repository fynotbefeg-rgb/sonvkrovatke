# SEO с Claude: план фактической демонстрации

2026-10-14. Роман выбрал показ реальной работы инструментов с честным указанием
расходов. Это уточнение угла, не отмена действующего R06 и не разрешение платных
запросов. Основа принята в переписке через владельца; серверная квитанция не проверена.

## Кадры и доказательства

| Кадр | Действие | Что подтвердить | Текущее состояние |
|---|---|---|---|
| Один из трёх принятых хуков | Поставить задачу проверки сайта | Понятная связь с последующей проверкой | Тексты приняты в переписке |
| GSC MCP | Прочитать запросы/страницы разрешённого ресурса, выбрать конкретный пример по показам/кликам | Реальный ответ именно MCP, период, ресурс, фильтры, строки результата | Реальное подключение не выполнено; Drive OAuth и вход Edge его не заменяют |
| OpenSEO | На том же примере выполнить один заранее ограниченный запрос, показать результат и расход | Модель запроса, источник DataForSEO, дата, реальный ответ и фактический расход | API не запускался; нужна отдельно согласованная стоимость и приватный ключ |
| GEO Optimizer | Запустить basic audit разрешённой страницы, затем вручную проверить одну рекомендацию | Версия, команда, исходный JSON и независимая проверка факта | Есть исторический basic audit 4.19.0 на example.com/install.download; это не idco.ru и не новый запуск |
| Финал | Карточка «страница → наблюдение → источник → следующий шаг» | Только проверенные выводы, без обещания роста/цитирования | Заполнить после реальных проверок; пока только макет |

Документация и экран цены показывают возможности/условия, но не заменяют
фактический запуск OpenSEO. Анализ выгрузки GSC допустим как самостоятельный
пример, но не выдаётся за подключение GSC MCP. Не имитировать OAuth, ответы API,
показатели клиента или результаты исправлений.

## Безопасная подготовка следующего этапа

1. Проверить, доступна ли ранее переданная выгрузка Search Console idco.ru.
   Обработать её локально, без публикации исходных бизнес-данных; зафиксировать
   период/тип поиска/фильтры и кандидат запроса/страницы. Не запрашивать заново
   уже имеющийся файл. Экспорт не доказывает наличие технической ошибки и не
   показывает работу MCP.
2. Для GSC MCP подготовить изолированную конфигурацию только чтения и проверить
   OAuth scope и отсутствие доступных операций записи. Старый сервер имеет
   webmasters scope и не становится read-only от GSC_ALLOW_DESTRUCTIVE=false.
   Нужны отдельные доступ/авторизация владельца ресурса; не брать cookies/секреты.
3. Для OpenSEO составить ровно один запрос и оценку расходов по действующим
   условиям, не запускать его. Показать владельцу конкретный запрос, предел
   расходов и способ ограничения. Если платные данные не разрешены, этот кадр
   остаётся обзором документации с явным указанием «не запускал».
4. Для GEO выбрать разрешённую страницу, фиксированную версию и basic audit
   без citations/fix/apply/LLM. Один результат проверить независимо. Старый
   ложноположительный пример доказывает необходимость проверки рекомендаций,
   а не дефект любой новой версии.

Исходная основа остаётся неизменной. Если реальный пример требует изменения
произносимого текста, показать Роману точную новую редакцию, не переносить старое
согласование автоматически. Финальная фраза/CTA и платформенные окончания ещё
не утверждены. До выпуска отдельно разрешить соответствие нового обзорного угла
R06: указание платной зависимости само по себе не проходит требование бесплатной
реализации для зрителя.

## Задание Claude — подготовка, без живых платных операций

Прочитай этот план и SEO_PLUGIN_VIDEO_BRIEF.md из ветки
feature/codex-seo-plugin-brief-20261013. Проверь наличие переданной выгрузки idco.ru
и подготовь локальную карточку одного примера с доказательствами. Подготовь
проверяемый план GSC только чтения и один проект запроса OpenSEO с оценкой цены.
Сохрани отчёт вне Git, если он содержит клиентские данные; в отдельной ветке/PR
публикуй только обезличенный метод и ограничения. Не запускать платные API,
генерацию Gemini, HeyGen, монтаж и производство; не менять Google согласования,
секреты, бот или супервизор. Не заявлять подключение MCP по результату CSV.
Итог — четыре строки и одно конкретное действие, если потребуется доступ.
