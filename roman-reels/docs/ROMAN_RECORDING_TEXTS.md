# Роман — комплект текстов для окончательного утверждения

Окончания уже утверждены по сообщению владельца. Ниже полный комплект: три хука, одна общая основа и два окончания на каждую тему. Нужно утвердить хуки и основу либо указать правки. Пока не записывать голос: тексты ещё на проверке.

## ИИ-аудит сайта бизнеса

### Три хука

1. Сайт есть, а клиентов из поиска нет? Покажу, что проверить с помощью ИИ.

2. Не проси нейросеть «вывести сайт в топ». Дай ей данные о том, что мешает твоему сайту.

3. Прежде чем заказывать SEO-аудит, собери данные сайта — и попроси ИИ составить план проверки.

### Общая основа

Начни с данных, а не с обещаний нейросети. Возьми отчёт Google Search Console, список важных страниц и тексты страниц с услугами. Если нужен технический обход сайта, используй отдельный инструмент: обычный чат не доказывает, что проверил все ссылки и настройки. Передай полученные данные Claude и попроси разделить выводы на подтверждённые ошибки, предположения и вопросы для проверки. Например: какие страницы не индексируются, где заголовок не объясняет услугу и какие ссылки требуют внимания. Для каждого пункта попроси указать источник и следующий шаг. Потом проверь предложенные исправления и передай технические задачи специалисту. Так ИИ помогает разобрать данные и подготовить план, но не гарантирует место в поиске. Начни с одной страницы своего бизнеса и сравни результат до и после исправлений.

### Утверждённые окончания

**Instagram:** Хочешь начать проверку своего сайта? Напиши «САЙТ» в комментариях.

**Tiktok:** Хочешь начать проверку своего сайта? Напиши «САЙТ» в личные сообщения.

## Одна идея для YouTube, Instagram и Telegram

### Три хука

1. Одна идея для бизнеса — три разных публикации. Покажу, как подготовить их с помощью ИИ.

2. Ты каждый раз придумываешь контент заново для YouTube, Instagram и Telegram? Начни с одной идеи.

3. Нейросеть не должна вести твой бизнес вслепую. Дай ей одну тему — и получи черновики для трёх площадок.

### Общая основа

Начни с одного вопроса, который тебе задают клиенты. Добавь в Claude описание своего бизнеса, аудиторию и проверенные факты. Попроси сначала сформулировать одну главную мысль, а потом адаптировать её под три площадки. Для YouTube нужен сценарий с объяснением и примером. Для Instagram — короткий Reels с сильным началом и одним понятным выводом. Для Telegram — пост, который можно прочитать без просмотра видео. Не проси просто скопировать один текст три раза: у каждого формата своя подача. Проверь факты, убери выдуманные результаты и поправь текст под свой голос. Затем запиши материал. На первом этапе подготовку черновиков можно делать без подключения соцсетей. Автоматическая публикация — отдельный шаг, которому нужны доступы и проверка. Начни с одной идеи и оцени каждый черновик перед публикацией.

### Утверждённые окончания

**Instagram:** Хочешь адаптировать одну идею под три площадки? Напиши «КОНТЕНТ» в комментариях.

**Tiktok:** Хочешь адаптировать одну идею под три площадки? Напиши «КОНТЕНТ» в личные сообщения.

## Ответ для утверждения

Можно ответить: «Утверждаю весь комплект: обе основы и все шесть хуков». Если нужны правки — указать тему и фрагмент. Изменённый текст возвращается на утверждение.

После утверждения можно записать отдельно три хука, одну основу и два окончания для каждой темы. Сборка: один из хуков → основа → окончание нужной площадки.
