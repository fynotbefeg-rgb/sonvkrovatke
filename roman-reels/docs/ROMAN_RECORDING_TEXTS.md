## Проверка кнопки заявки через Playwright MCP — версия 3

### Три хука

1. Кнопка «Оставить заявку» есть. А нужная страница за ней открывается? Вот как проверить это через MCP.

2. После правок сайта проверь путь к заявке. Покажу проверку кнопки через Playwright MCP: ошибка, скриншот, повторный запуск.

3. Не проси ИИ просто оценить сайт. Дай ему браузер через MCP и конкретную задачу: проверить кнопку заявки.

### Общая основа

Покажу на учебном сайте. Подключаем к Claude Code официальный Playwright MCP от Microsoft: команда установки будет на экране. Он даёт помощнику инструменты управления браузером. В меню /mcp проверяем подключение. Затем даём задачу: «Открой мой тестовый сайт, нажми “Оставить заявку”, сохрани адрес перехода и скриншот ошибки. Форму не отправляй». Сам маршрут мы уже проверили через этот MCP программным исполнителем: кнопка открыла несуществующую страницу — ошибка 404. Исправили ссылку, повторили проверку: нужная страница открылась со статусом 200. Получается конкретная проверка пути к заявке с доказательством ошибки. Она не проверяет доставку заявки в CRM: для этого нужен отдельный тест. Чтобы запускать проверку регулярно, понадобится расписание; одна установка MCP его не создаёт.

## Соцсети — версия 1, на доработке

### Три хука

1. Одна идея для бизнеса — три разных публикации. Покажу, как подготовить их с помощью ИИ.

2. Ты каждый раз придумываешь контент заново для YouTube, Instagram и Telegram? Начни с одной идеи.

3. Нейросеть не должна вести твой бизнес вслепую. Дай ей одну тему — и получи черновики для трёх площадок.

### Общая основа

Начни с одного вопроса, который тебе задают клиенты. Добавь в Claude описание своего бизнеса, аудиторию и проверенные факты. Попроси сначала сформулировать одну главную мысль, а потом адаптировать её под три площадки. Для YouTube нужен сценарий с объяснением и примером. Для Instagram — короткий Reels с сильным началом и одним понятным выводом. Для Telegram — пост, который можно прочитать без просмотра видео. Не проси просто скопировать один текст три раза: у каждого формата своя подача. Проверь факты, убери выдуманные результаты и поправь текст под свой голос. Затем запиши материал. На первом этапе подготовку черновиков можно делать без подключения соцсетей. Автоматическая публикация — отдельный шаг, которому нужны доступы и проверка. Начни с одной идеи и оцени каждый черновик перед публикацией.

## Настройка и проверенные факты — не речь

Команда на экране, не читать вслух:
claude mcp add --transport stdio playwright -- npx -y @playwright/mcp@0.0.83 --headless --isolated
Нужны Node.js и Claude Code. После добавления проверить статус в /mcp; при ошибке подключения сначала устранить её. Windows и живая сессия Claude ещё не проверены. Демонстрация выполнена программным исполнителем на нашем учебном сайте: 404 → исправление ссылки → 200. Проверка не измеряет продажи и не отправляет формы. Источники: https://github.com/microsoft/playwright-mcp и https://code.claude.com/docs/en/mcp
