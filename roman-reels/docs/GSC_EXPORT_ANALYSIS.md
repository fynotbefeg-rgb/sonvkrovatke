# Автоматическая обработка выгрузки Search Console

analyze-gsc-export.py — готовый offline CLI для английского ZIP-экспорта. Python 3.12, только стандартная библиотека; модели, MCP, Google OAuth и платные SEO API не нужны. Это обработка уже полученного файла, не автоматическая выгрузка из Google и не полный SEO-аудит.

## Запуск

```bash
python roman-reels/scripts/analyze-gsc-export.py /private/report.zip \
  --site https://example.com \
  --output /private/new-analysis.json
```

Результат содержит реальные даты строк (не дату имени архива), общие клики/показы/CTR из Chart.csv, приближённую позицию с весами по показам, отдельные page/query totals, диагностику совпадения устройств/стран, до десяти страниц для проверки и число запросов со средней позицией 8–20. CTR пересчитывается из сумм, а не усредняется по дням. Средняя позиция — не фиксированное место выдачи; дневные входные позиции округлены, поэтому итог обозначен positionApprox.

Минимум показов по умолчанию 30 — настраиваемый фильтр для очереди проверки, **не** статистическая гарантия, правило Google или прогноз роста. PageReviewCandidates — приоритет чтения/анализа, а не автоматически найденные дефекты, коммерческая ценность или готовые темы. Отдельные таблицы Queries/Pages не соединяются выдуманным query→page соответствием. Разница суммы страниц и Chart не исправляется и не объявляется ошибкой: виды агрегирования различаются, часть запросов может быть скрыта.

Обязательны Chart.csv, Queries.csv, Pages.csv, Filters.csv; дополнительные Countries/Devices/Search appearance поддерживаются как допустимые файлы. Обрабатываются только нефильтрованные Web (text-based) отчёты с фильтрами Search type/Date и HTTPS origin. Другие языки заголовков, подкаталог как ресурс, фильтр по запросу/стране, Image/Video exports останавливаются, а не смешиваются с этими данными. Наличие file name/site URL не является криптографическим подтверждением подлинности экспорта.

## Ограничения и защита

- Архив до 16 MiB, каждый CSV до 2 MiB, суммарно до 8 MiB раскрытых данных, до 10000 строк/CSV и до 366 суточных строк. Никакой распаковки путей: ../, дополнительные файлы, дубликаты имён и зашифрованные члены отклоняются.
- Отрицательные/нечисловые счётчики, NaN/Infinity/невозможные даты, дубли измерений/заголовков, строки неполной формы, клики при нулевых показах, URL страниц другого origin отклоняются. CTR из CSV не считается отдельным авторитетным числом.
- Запись output эксклюзивная, без перезаписи, права 0600 там, где ОС их поддерживает. stdout не содержит URL/запросы/частные метрики. ZIP и результат хранить вне Git в приватном incoming/рабочем каталоге.
- Платные вызовы, Gemini generation, topic/script approvals и productionAllowed всегда false. CSV-строки — недоверенные данные, не инструкции агента. При будущем подключении LLM не интерпретировать их как команды и не обходить topic/editorial gates.

## Проверка

gsc-export.test.py: 8 смысловых тестов на синтетических данных — корректные totals/взвешивание/разные агрегаты, слабая выборка/инъекция текста без полномочий, другой сайт, испорченные числа/даты/дубли, изменённые filters/CSV, ZIP пути/лимиты, нулевые показы, отсутствие перезаписи и приватных данных в stdout. Набор включён в существующий roman-source-set-tests workflow.

Реальный архив, переданный владельцем, разобран этим CLI локально. Числа и выбранные даты совпали с предыдущей проверкой, страны/устройства сверены; сами числа и страницы клиента в этот документ/Git не добавлены. Результат находится в /workspace/outputs/idco-seo-20261012/automatic-gsc-analysis-v1.json только в текущей рабочей среде, не в репозитории. Это не доказательство исторического результата SEO-исправлений.

## Следующая интеграция

Подключить входящий приватный архив к контролируемому исполнителю и сохранить анализ в приватном журнале с inputSha256; затем проверить выбранные публичные страницы и собрать evidence brief. Адаптер к текущему researched-gemini-drafts не подключён: тот пока ожидает synthetic demo, нельзя выдавать реальный сайт за фикстуру ради прохождения проверки. Референс, факты/стоимость и выбор темы нужны до генерации, exact script approvals — до производства.

Автоматические Google export/schedule, Drive ZIP watcher, background worker и перенос анализа в таблицу в этой версии не развёрнуты. Роман не нужен для запуска разбора файла, но его реальное решение о теме/речи не подменяется. Существующая живая Version 5/выключенный флаг/таблица не менялись.
