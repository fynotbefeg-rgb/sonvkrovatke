## Редакционное решение и R06

Не использовать утверждения «три бесплатных плагина», «экономия $3346», «полностью заменяет Ahrefs»
и «ИИ будет цитировать ваш сайт вместо конкурентов». Найденная обязательная платная зависимость
OpenSEO нарушает R06 для демонстрации бесплатной связки. Не обходить правило бесплатным trial,
чужим ключом, студийной подпиской или словом open-source. Проверка всей бесплатной модели/интеграций
остаётся незавершённой. Готового бесплатного end-to-end решения этим брифом не заявлено.

Рабочий угол: «Что реально дают SEO-инструменты для Claude и где у них ограничения». Это предложение
для редакционного решения, а не автоматическое изменение уже понравившейся Роману основы.
Если требование — именно бесплатное решение, для первого практического примера исследовать
экспорт своих данных GSC + базовые локальные проверки/GEO без OpenSEO и provider calls. Такой путь
не является показом трёх установленных плагинов; нельзя подменить им обещание исходного рилса.

## Предварительный текст новой основы — только для обсуждения угла

Claude можно подключить к SEO-инструментам, но у каждого своя задача. Первый — GSC MCP: даёт доступ
к данным твоего сайта в Search Console, чтобы разобрать запросы, показы и клики. Для этого нужно
отдельно настроить доступ Google. Второй — OpenSEO: помогает работать с ключами, позициями и
бэклинками. Код открытый, но данные DataForSEO оплачиваются отдельно. Третий — GEO Optimizer:
проверяет признаки доступности и понятности страницы для поисковых систем с ИИ. Его рекомендации
нужно перепроверять, а высокий балл не гарантирует цитирование. Практический результат — выбрать
страницу по данным, подтвердить проблему и получить список действий. Установка плагинов сама
по себе не исправляет сайт и не гарантирует рост трафика.

Этот текст НЕ отправлять как готовую основу на утверждение/запись: R06 не пройден, рабочий угол требует
решения, точная ранее понравившаяся основа пока не установлена. Он не меняет ROMAN_RECORDING_TEXTS.md,
Google, прежние тексты, hashes или квитанции. Новые три хука из PR49 сохраняются без редакции;

## Что показывать и что ещё не готово

| Экран | Можно подготовить сейчас | Требуется перед настоящей записью |
|---|---|---|
| GSC MCP | Публичный список возможностей, схема данные → вопрос → проверка | Одобренный ресурс/выгрузка, проверенный режим чтения, реальный результат; не рисовать фиктивную OAuth-сессию |
| OpenSEO | Публичная документация зависимости DataForSEO и цены данных | Не запускать API, не показывать якобы найденные ключи/ссылки. Для бесплатного решения этот инструмент исключён |
| GEO | Документация базового audit и границы score/citations | Перепроверенные наблюдения разрешённой страницы; не показывать высокий score как будущий рост/цитирование |
| Финал | Макет карточки: URL, наблюдение, источник, следующий шаг | Заполнить только реальными данными; макет не выдавать за аудит idco.ru |

Следующий технический шаг: согласовать проверяемый бесплатный путь или изменить угол обзора с
прозрачным указанием платных зависимостей. Затем подтвердить точную основу с Романом и подготовить
речевой packet. Установка MCP, Google OAuth, изменения сайта, новые SEO API, Gemini, HeyGen, видео,
монтаж, очередь и production в этой проверке не выполнялись. Цель разгрузки Claude через Gemini
сохраняется отдельно; её блокер бюджета PR44 не считается исправленным этим брифом.
