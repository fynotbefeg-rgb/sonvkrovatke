# Локальная модель для SEO: фактический опыт

Дата: 2026-10-11. Две модели Qwen2.5 Instruct (0.5B и 1.5B), квантование Q4_K_M, официальный репозиторий Qwen. Модельные лицензии Apache 2.0; llama.cpp MIT. Версии, URL и SHA256 сохранены. Бинарники и веса находятся вне Git в scratch. Подключений к платным модельным API не было. Расходы облачной среды не измерены; нулевая плата API не означает нулевую стоимость оборудования/вычислений.

## Опыт

Шесть действительных локальных вызовов, по три на модель. Одинаковый английский запрос, temperature 0, два CPU-потока, контекст 2048, до 256 выходных токенов, таймаут 90 секунд. Учебные случаи: noindex на странице, которую нужно индексировать; исправленная директива; вопрос об индексации/трафике без данных. Порядок случаев одинаковый, повторов и смены промпта для красивого результата не было.

Модель не управляла браузером: она получила ограниченные наблюдения, соответствующие существующему учебному отчёту. Это проверка интерпретации данных, не полный SEO-аудит. Русская речь, полный сайт, реальный Search Console и Windows не тестировались.

| Кандидат | Совпадение вердикта | Фактическая проблема | Решение |
| --- | --- | --- | --- |
| Qwen 0.5B | 1 из 3 | Одобрил noindex; выдумал индексацию и рост трафика; даже правильный pass сопровождается неподтверждёнными выводами | Отклонён для этой инструкции |
| Qwen 1.5B | 2 из 3 | Одобрил noindex вопреки намерению владельца; обобщил одну проверку до всех best practices. В случае без данных правильно ответил unknown, но добавил непроверенные инструменты | Отклонён для этой инструкции |

Совпадение вердикта не означает прохождение фактической проверки. Ответы с лишними символами/Markdown и дополнительными полями не являются готовым строгим JSON. Диагностическое извлечение JSON в assessment используется только для сравнения; оно не разрешает применение ответа в производстве.

## Доказательства и повторение

Все запросы, исходные stdout/stderr, команды и время сохранены в research/site-technical-seo/local-model-probe-2026-10-11/. expected-results.json задаёт ожидаемые выводы; fixture-binding.json связывает наблюдения с учебным отчётом. run-probe.py запускается с --engine, --model и новым --output; не загружает зависимости, не использует API, не меняет сайт или таблицу. Скрипт нужен для воспроизведения опыта в этой Linux-среде; инструкция запуска на Windows ещё не проверена.

## Вывод для разработки

В этих условиях наличие бесплатной локальной модели не обеспечивает качество. Не заменять ею текущий Gemini и не переписывать согласованную речь на основании этого опыта. Технический статус проверки должен приходить из проверяемых наблюдений, а предложение модели — проходить отдельную фактическую проверку. Следующий ограниченный опыт: дать модели явно размеченные факты и допустимые границы вывода, испытать полезные задачи/правки и неизвестные данные; сравнить с текущим опытом. До успешного опыта не отправлять новый текст Роману и не объявлять бесплатную ИИ-связку готовой. Свежий популярный внешний референс по-прежнему нужен.
