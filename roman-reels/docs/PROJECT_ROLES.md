# Распределение работы

Зафиксировано пользователем и сохранено 2026-10-10.

| Инструмент | Роль |
|---|---|
| ChatGPT | Планирование, контроль автоматизации, помощь с настройками |
| Claude Code | Написание и изменение кода Remotion, монтажных шаблонов и GitHub Actions |
| Codex | Проверка, доработка и тестирование непосредственно в репозитории |
| Gemini | Генерация сценариев Reels |
| HeyGen | Создание аватара через автоматизацию пользовательского интерфейса на удалённом ноутбуке, без API; подключение ещё не настроено |
| Telegram-бот | Управление решениями Романа и кнопка запуска утверждённого производства; ещё не реализован |
| Google Drive | Хранение исходников и готовых роликов |
| GitHub Actions + Remotion | Автоматический запуск обработки и монтажа после проверок |
| Apify | Сбор доступных данных роликов для исследования; новые оплачиваемые запуски только в согласованных пределах |

Claude Code и Codex используют один репозиторий и `automation/roman-reels-v1`. Каждый проверяет актуальность origin перед изменениями; параллельные изменения одного файла нужно согласовать и проверить, а не переписывать force push.

Актуальная целевая архитектура: [TELEGRAM_LAPTOP_PIPELINE.md](TELEGRAM_LAPTOP_PIPELINE.md). Роман утверждает сценарий и хуки; производство запускается кнопкой бота. Экспорт HeyGen с телефона — резервный вариант, не конечная цель. Место утверждения и права запуска должны быть подтверждены перед реализацией бота.

Текущий первый заказ Claude Code: [CLAUDE_CODE_TASK_01.md](CLAUDE_CODE_TASK_01.md). Подготовлена [передача через GitHub Actions](CLAUDE_CODE_AUTOMATION.md), чтобы не копировать задания вручную. Она пока выключена, OAuth и реальный запуск не проверены. Прямого подключения к пользовательской браузерной сессии Claude Code у Codex нет. Наличие файла задания не означает, что Claude Code его получил или выполнил.
