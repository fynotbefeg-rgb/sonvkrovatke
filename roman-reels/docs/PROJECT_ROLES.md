# Распределение работы

Зафиксировано пользователем и сохранено 2026-10-10.

| Инструмент | Роль |
|---|---|
| ChatGPT | Планирование, контроль автоматизации, помощь с настройками |
| Claude Code | Написание и изменение кода Remotion, монтажных шаблонов и GitHub Actions |
| Codex | Проверка, доработка и тестирование непосредственно в репозитории |
| Gemini | Генерация сценариев Reels |
| HeyGen | Создание видео с цифровым аватаром Романа; пока вручную без API |
| Google Drive | Хранение исходников и готовых роликов |
| GitHub Actions + Remotion | Автоматический запуск обработки и монтажа после проверок |
| Apify | Сбор доступных данных роликов для исследования; новые оплачиваемые запуски только в согласованных пределах |

Claude Code и Codex используют один репозиторий и `automation/roman-reels-v1`. Каждый проверяет актуальность origin перед изменениями; параллельные изменения одного файла нужно согласовать и проверить, а не переписывать force push.

Текущий первый заказ Claude Code: [CLAUDE_CODE_TASK_01.md](CLAUDE_CODE_TASK_01.md). Прямого подключения к пользовательской сессии Claude Code у Codex нет: сохранённое задание пользователь передаёт туда одним сообщением. Наличие файла задания не означает, что Claude Code его получил или выполнил.
