# Распределение работы

Обновлено по авторитетному ТЗ 3.0 пользователя, 2026-10-10.

| Инструмент | Роль |
|---|---|
| ChatGPT | Планирование, контроль автоматизации, помощь с настройками |
| Claude Code | AI Montage Director, Remotion, субтитры, смысловые вставки, стили и визуальные тесты |
| Codex | Главный разработчик автоматизации: Gemini, Sheets, очередь, Windows worker, Drive, анализ речи, интеграция, рендер/QC, Actions, идемпотентность |
| Gemini | Генерация сценариев Reels |
| HeyGen | Создание аватара через автоматизацию пользовательского интерфейса на удалённом ноутбуке, без API; подключение ещё не настроено |
| Google Sheets | Роман утверждает точные актуальные сценарии и хуки; живой полный цикл личности/отзыва ещё не проверен |
| Telegram-бот | Кнопка запуска уже утверждённого производства; transport ещё не реализован |
| Google Drive | Хранение исходников и готовых роликов |
| GitHub Actions + Remotion | Автоматический запуск обработки и монтажа после проверок |
| Apify | Сбор доступных данных роликов для исследования; новые оплачиваемые запуски только в согласованных пределах |

Интеграционная ветка `automation/roman-reels-v1`. Codex: `feature/codex-pipeline`, Claude: `feature/claude-montage`, обе от актуальной integration base; PR в automation. main не менять. Проверять origin перед работой, согласовывать общий контракт, не переписывать историю force push.

Актуальные архитектура и задачи: [ROADMAP.md](ROADMAP.md), [CLAUDE_TASKS.md](CLAUDE_TASKS.md), [CODEX_TASKS.md](CODEX_TASKS.md), [INTEGRATION_CONTRACT.md](INTEGRATION_CONTRACT.md). Место утверждения задано ТЗ: существующая Sheets. Права запуска бота остаются отдельной серверной настройкой. HeyGen UI допустимость не подтверждена; см. [проверку условий](HEYGEN_BROWSER_AUTOMATION.md). Windows сейчас не нужен для облачного монтажа.

Текущий первый заказ Claude Code: [CLAUDE_CODE_TASK_01.md](CLAUDE_CODE_TASK_01.md). Подготовлена [передача через GitHub Actions](CLAUDE_CODE_AUTOMATION.md), чтобы не копировать задания вручную.
