# Проверка сценариев с телефона

Роман подтвердил через пользователя, что у него нет аккаунта GitHub. Основной интерфейс утверждения остаётся Google Sheets. Читать публичный документ по ссылке GitHub можно без регистрации; это только просмотр, не действие утверждения.

## Подготовлен первый пилот

[Полный текст трёх вариантов](../research/roman-pilot-review/REVIEW.md): «База знаний, чтобы ИИ не выдумывал цены». Варианты отличаются хуком, основа одна. Весь текст речи, включая выбранный хук, находится в `script_text`; повторно добавлять хук перед озвучкой не нужно. По 121–124 слова; длительность ещё не измерена. Для монтажа нужна реальная демонстрация на тестовом прайсе, без личных данных и выдуманных результатов Романа.

Это новые редакционные черновики, а не транскрипция Instagram и не результат запроса Gemini. Они не загружены в Google, не утверждены, не озвучены и не совместимы автоматически со статическими темами текущего Remotion-шаблона.

`snapshot.json` сохраняет точный текст, ревизию и SHA-256 каждого варианта. Хеш проверяет соответствие текста, но не личность Романа. Файл проверки не считается производственным разрешением.

## Подготовка следующих пакетов

Из корня репозитория:

```bash
node roman-reels/scripts/prepare-script-review.mjs drafts.json NEW-review-directory
node roman-reels/scripts/validate-approvals.mjs NEW-review-directory/snapshot.json
node roman-reels/scripts/prepare-script-review.test.mjs
```

Каталог результата должен быть новым: команда не перезаписывает предыдущую проверку. При изменении текста нужно увеличить ревизию и подготовить новый пакет. Команда принимает только `pending_approval`, не добавляет автора/дату утверждения, не вызывает API и не запускает производство.

Точное содержание и сохранение dropdown подтверждены чтением Google. Все варианты по-прежнему «На проверке». Личное утверждение Романа и реальная доступность `e.user` ещё не проверены; пустая очередь не доказывает защиту утверждений.

1. Получить настоящий Google email Романа для разрешённого списка утверждающих. Email не предоставляет Codex доступ к Apps Script.
2. Установить и проверить подготовленный защищённый механизм из [Apps Script README](../apps-script/README.md). Прямая запись в Apps Script недоступна текущим инструментам; исходный код на телефоне восстановлен, повторять неудачную замену всего файла нельзя. Рабочий способ установки ещё требуется выбрать. Если Google не передаёт идентичность редактора, потребуется отдельная аутентификация.
3. Только после успешного реального теста утверждения допускать сценарий к приёму видео. До этого чтение пакета или значение «Утверждено» в старой таблице не снимает блокировку производства.
