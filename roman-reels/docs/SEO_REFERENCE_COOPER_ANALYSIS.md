## Данные и происхождение

Первичная публичная страница Instagram: дата, автор и тема совпали.
Публичный Instagram embed того же shortcode/media ID дал:
430 253 `video_view_count`, 13 643 лайка, 32 524 комментария.
Каталог Pictame показал отдельно 919 554 `playCount`.
Эти два разных счётчика не объединять и не называть уникальным охватом.
Охват и сохранения неизвестны. Комментарии стимулируются кодовым словом SEO;
их число не доказывает число клиентов или качество обсуждения.

Файл получен по публичной ссылке видео с карточки Pictame, без обхода защиты,
без авторизации и без платных Actor/API. FFprobe: 720×1280, 30 fps, звук,
длительность 54.029977 с. Разобраны 18 кадров с шагом около трёх секунд
и локальная английская расшифровка faster-whisper-small CPU int8.
Непрерывный просмотр и ручная проверка каждого слова не выполнялись.
Распознавание ошибается в названиях Claude/ChatGPT; речь не выдавать за
дословную проверенную цитату. Скачанный MP4 и чужие кадры не публикуются
в Git и не используются в наших роликах.

элементов на просмотры не установлены.

## Что берём для Романа

1. Конкретная задача предпринимателя: проверить сайт и получить список
   исправлений с адресами страниц и доказательствами.
2. Три разных коротких вступления, затем одна общая основа, как в нашей сборке.
3. Собственная демонстрация: входные данные → действие в Claude → результат
   по конкретной странице → перепроверка. Для Search Console — коротко показать
   «Экспорт», если используем этот маршрут.
4. Оставить лицо Романа между демонстрациями, пословные субтитры и акценты,
   связанные с фактической речью. Не забивать кадр всем чек-листом сразу.
5. В результате показать «проблема / URL / доказательство / правка / проверка».
   Учебный noindex на нашем стенде явно обозначить учебным примером.

Не переносить обещания «заменяет агентство», «поднимает позиции», «всё бесплатно»,
«за три минуты» или «полностью исправляет без человека». Наш Claude-промпт
пока не испытан. SEO, скорость и фактическая индексация требуют соответствующих
инструментов/данных; открытый skill не отменяет стоимость модели и внешних API.

## Подготовка монтажа для Claude Code

Это задание для будущей работы, а не выполненная интеграция:
- Использовать существующую RomanFactoryV1, без нового проекта.
- Вставки собственного экрана привязать к распознанным словам/сегментам.
- Читать только материалы с подтверждёнными правами; у каждого asset указать
  происхождение и связь с показанной проверкой.
- При отсутствии записи экрана использовать оригинальную карточку с явной
  маркировкой «учебный пример»; не изображать реальный клиентский отчёт.
- Сохранить схему 3 хука + 1 основа, контракт, исходный звук, safe zones и QC.
- Сначала один тестовый вариант: читаемость URL/ошибки, субтитров и лица;
  затем три варианта. Продакшен только после утверждения актуального текста.
