## Практический путь первого опыта

Предлагаемый результат для владельца бизнеса: список страниц и запросов,
которые стоит проверить, с исходными числами и конкретным следующим действием.
Не обещать рост трафика или продаж от одного промпта.

1. В Search Console выбрать сайт, Web и определённый период. Сохранить параметры
   отчёта вместе с CSV и выгрузить таблицы запросов и страниц.
2. Для анализа запроса по конкретной странице нужен экспорт с фильтром Page
   и таблицей Queries либо данные API с обеими размерностями. Две отдельные
   сводки Queries и Pages нельзя соединить в пары запрос–страница догадками.
3. Посчитать CTR как clicks / impressions. Сравнивать равные периоды с одинаковыми
   фильтрами. Проверить пропуски, нули, лимиты выгрузки и итоговые суммы.
4. Передать проверенные данные Claude: попросить наблюдения, гипотезы и список
   задач отдельно. Не позволять модели придумывать отсутствующие числа.
5. Совместить с техническим отчётом: HTTP-ответы, robots, noindex, sitemap,
   canonical и редиректы. Наш существующий fixture показывает только учебные
   проверки; он не является аудитором любого клиентского сайта.
6. Получить отчёт и собственную запись экрана. Проверить выводы и лишь затем
   подготовить Gemini-бриф, одну основу и три хука с новым утверждением.

Search Console подтверждает показатели и экспорт:
https://support.google.com/webmasters/answer/7576553?hl=en
https://support.google.com/webmasters/answer/17011259?hl=en
Анонимизированные и обрезанные строки ограничивают полноту данных. Значения
неизвестно/недоступно при экспорте могут стать нулём. Отсутствие строки не
доказывает отсутствие спроса. CTR не показывает конверсию в заявки.

CSV-путь не требует стороннего MCP; тариф и лимиты самого Claude проверять
отдельно. Search Console требует доступа к подтверждённому ресурсу. Для нового
сайта без истории начинать с технического отчёта, не выдумывать поисковый трафик.
API/MCP подключение оставить следующим этапом после проверки ручного опыта.

## Промпт для будущего проверяемого опыта

> Проанализируй приложенные данные Search Console. Сначала перечисли файлы,
> колонки, периоды, фильтры и недостающие сведения. Не соединяй отдельные
> сводки запросов и страниц в пары. Для каждой рекомендации покажи исходную
> строку, цифры, наблюдение, гипотезу и способ её проверить. Не обещай рост
> позиций, не выводи причину падения только из CTR. Если есть только агрегаты,
> укажи ограничения. Сформируй приоритетный список задач владельцу и разработчику.
> Не меняй сайт. Отсутствующие данные помечай «неизвестно».

Промпт подготовлен Codex, через Claude пока не выполнен. Реальных CSV сайта
в текущем этапе нет; синтетические числа нельзя выдавать за результаты Романа.
