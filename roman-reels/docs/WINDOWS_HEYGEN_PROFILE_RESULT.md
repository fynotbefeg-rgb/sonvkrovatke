# Windows: отдельный профиль Edge для HeyGen и ручная проверка аватаров

2026-10-12. Выполнено Claude Code на Windows-ноутбуке по команде владельца. Ничего не генерировалось. Тариф, настройки аккаунта и голос не менялись, файлы в HeyGen не загружались.

## Профиль

- Создан новый постоянный каталог `LOCALAPPDATA/RomanReels/browser-profiles/heygen` (вне Git). Профиль `google-project` и оба MCP (`playwright`, `playwright-google`) не менялись. Процесс google-project продолжал работать.
- Edge запущен обычным локальным запуском (`--user-data-dir`, `--no-first-run`, `https://app.heygen.com`), **без** `--remote-debugging-port`, без MCP и без Playwright.
- Вход выполнил владелец вручную через Chrome Remote Desktop. Cookies не копировались, пароль и коды не считывались. Окно оставлено открытым.

## Почему без автоматизации

HEYGEN_BROWSER_AUTOMATION.md фиксирует `policy_permission_required`: раздел 2 Terms HeyGen ограничивает стороннюю автоматизацию и автоматический доступ/сбор данных, письменного разрешения нет. Поэтому:
- для профиля heygen MCP не регистрировался;
- по страницам HeyGen не выполнялось ни одного клика, ввода, скрипта или сетевого запроса от Claude;
- навигацию выполнял владелец. Claude по его команде «снимай» делал только снимок окна этого профиля средствами Windows (`PrintWindow`).

Снимки содержат лицо Романа, поэтому остались локально во временной папке сессии и в Git не добавлены.
