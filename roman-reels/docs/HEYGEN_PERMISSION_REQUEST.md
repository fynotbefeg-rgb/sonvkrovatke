# Вопрос HeyGen о выбранной браузерной автоматизации

Письменный ответ нужен для установления допустимости конкретного workflow; решение владельца проекта не заменяет разрешение сервиса.

Текст для обращения через официальный support chat HeyGen:

> Hello! I want to confirm whether my account's plan permits browser automation with Playwright on my own Windows laptop, using the normal website and an authorized local browser profile, without the HeyGen API.
>
> The workflow would insert an approved script or my client's authorized voice recording, select the client's existing authorized avatar, submit one generation at a time, monitor completion, and download only the MP4 generated in my account. >
> I will not bypass login, MFA, CAPTCHA, anti-bot protections, payment or usage limits, and will not access private backend endpoints. Is this specific workflow permitted under your terms and my plan? If permission or a different agreement is required, please describe the permitted approach and limits in writing before I implement it.

Перевод смысла: разрешено ли на собственном Windows-ноутбуке управлять обычным веб-интерфейсом Playwright для создания и скачивания собственных клиентских видео, без API и обхода защиты? Какие условия/лимиты применимы именно к аккаунту и тарифу?

Не передавать пароль, токен, cookies или личные голосовые файлы ради этого вопроса. Тариф/аккаунт сообщать только поддержке в её штатном авторизованном интерфейсе. Не устанавливать исполняющий HeyGen worker до подтверждения допустимого варианта. Очередь, cloud intake/монтаж и ручной экспорт можно развивать независимо.
